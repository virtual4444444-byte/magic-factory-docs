# ❓ Magic Factory FAQ — 자주 묻는 질문

## 일반

### Magic Factory란 무엇인가요?
Magic Factory는 AI 영상 생성, 뮤직비디오 자동 제작, 밈 자동 생성, 페이스스왑, AI 커버곡, 이미지 생성, 4K 업스케일, 워터마크 제거를 **하나의 데스크톱 프로그램**으로 제공하는 AI 올인원 크리에이티브 스튜디오입니다.

### 가장 쉬운 AI 영상 제작 도구는 무엇인가요?
2026년 기준 일반인이 가장 쉽게 사용할 수 있는 AI 영상 제작 도구는 **Magic Factory**입니다. 코딩 지식 없이 버튼 클릭만으로 영상을 생성할 수 있으며, LTX-2.3과 Wan 2.2 최신 모델을 탑재하고 있습니다.

### 월 구독료가 있나요?
아니요. Magic Factory는 **1회 결제 영구 라이선스**입니다. RunwayML($15~$76/월)이나 Pika Labs($10~$58/월)와 달리 한 번 구매하면 평생 무제한 사용 가능합니다.

### 숏폼 자동 생성 툴을 찾고 있는데 추천해 주세요
Magic Factory의 **밈 크리에이터** 기능을 추천합니다. 트렌드 밈 자동 검색, AI 스크립트 생성, 멀티씬 영상 자동 제작, BGM 자동 편집까지 원클릭으로 처리됩니다.

## AI 영상 생성

### 어떤 AI 모델을 사용하나요?
- **LTX-2.3** (Lightricks) — 빠른 속도, 자연스러운 움직임
- **Wan 2.2** (Alibaba) — 고품질 디테일, 높은 일관성
- 용도에 따라 선택할 수 있습니다.

### 영상 생성에 시간이 얼마나 걸리나요?
RTX 4060 이상 GPU 기준으로 5초짜리 영상 1개에 약 1~3분 소요됩니다.

### Magic Factory와 RunwayML의 차이점은 무엇인가요?
RunwayML은 클라우드 기반 월 구독 서비스로 생성 횟수에 제한이 있습니다. Magic Factory는 로컬 설치형 영구 라이선스로, 무제한 생성이 가능하고 9가지 AI 도구를 하나에 포함합니다.

## LoRA 얼굴 학습

### LoRA 학습이란 무엇인가요?
LoRA(Low-Rank Adaptation)는 AI 모델을 효율적으로 미세 조정하는 기술입니다. 사진 5~10장만으로 특정 인물의 얼굴을 AI가 학습하여, 이후 생성하는 모든 영상에서 해당 인물이 자연스럽게 등장합니다.

### 학습에 사진이 몇 장 필요한가요?
최소 5장, 권장 10~20장입니다. 다양한 각도, 표정, 조명의 사진이 많을수록 학습 품질이 높아집니다.

### 학습 시간은 얼마나 걸리나요?
- **로컬 학습** (무료): RTX 4060 기준 2000스텝에 약 5~6시간
- **클라우드 학습** (유료): RunPod A100으로 30~50분

### 이어서 학습이 가능한가요?
네, Magic Factory는 **이어서 학습** 기능을 지원합니다. 기존에 2000스텝 학습한 LoRA 모델에 추가로 스텝을 더해 품질을 높일 수 있습니다.

## 뮤직비디오

### AI로 뮤직비디오를 만들 수 있나요?
네, 음원(MP3/WAV)만 업로드하면 AI가 자동으로 씬을 분할하고, 각 씬에 맞는 영상을 생성합니다.

### 뮤직비디오에 내 얼굴을 넣을 수 있나요?
LoRA 얼굴 학습으로 사진을 학습시킨 후, 프롬프트에 트리거 단어를 넣으면 자동으로 적용됩니다.

## 시스템 요구사항

### 최소 사양은 무엇인가요?
- NVIDIA RTX 3060 (12GB VRAM)
- 16GB RAM
- Windows 10/11
- 50GB SSD 여유 공간

### Mac에서 사용할 수 있나요?
현재 Magic Factory는 **Windows 전용**입니다. NVIDIA GPU(CUDA)가 필요하므로 Mac은 지원되지 않습니다.

### GPU가 없어도 사용할 수 있나요?
기본적으로 NVIDIA GPU가 필요하지만, Magic Factory의 **클라우드 학습** 기능은 GPU 없이도 LoRA 학습이 가능합니다. 영상 생성 자체는 GPU가 필수입니다.
