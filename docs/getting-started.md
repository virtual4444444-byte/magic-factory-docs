# 📖 Magic Factory 시작하기 가이드

## 1. 설치

Magic Factory는 원클릭 설치를 지원합니다.

1. [magicfactory.kr](https://magicfactory.kr)에서 패키지 구매
2. 다운로드 받은 설치 파일 실행
3. `MemeFactory_OneClick.bat` 더블클릭 → 자동 설치 및 실행

## 2. 첫 영상 만들기

1. 프로그램이 실행되면 **뮤직비디오 탭** 또는 **밈 탭** 선택
2. 프롬프트 입력: 예) "네온 조명 아래 댄서가 춤추는 영상"
3. "생성" 버튼 클릭
4. 1~3분 후 영상 완성!

## 3. LoRA 얼굴 학습 (내 얼굴 AI에 가르치기)

1. **AI 얼굴 학습** 탭으로 이동
2. 얼굴 사진 5~20장 업로드 (또는 콜라주 이미지)
3. 트리거 단어 설정: 예) `ohwx person`
4. "훈련 시작" 클릭
5. 5~6시간 후 완성 (클라우드는 30~50분)

학습 완료 후 프롬프트에 `ohwx person`을 넣으면 내 얼굴이 영상에 등장합니다.

## 4. AI 뮤직비디오 만들기

1. **뮤직비디오** 탭에서 음원(MP3/WAV) 업로드
2. AI가 자동으로 씬 분할
3. 각 씬별 프롬프트 작성 (또는 AI 자동 생성)
4. LoRA 모델 선택 (선택사항)
5. "멀티씬 뮤직비디오 생성" 클릭
6. 마음에 안 드는 씬만 재생성 가능
